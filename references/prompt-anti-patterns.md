# Prompt Anti-Patterns（反 AI 八股完全清单）

来源：guonika 全站 8 个 LLM 入口的实战。每条规则都对应过具体翻车。

---

## 14 词黑名单（中文 SEO / 工业 B2B 写作）

| 词 | 为什么是八股 |
|---|---|
| 蓬勃发展 | 万能词，零信息量 |
| 未来可期 | 空话，无具体数据支撑 |
| 赋能 | 互联网黑话，B2B 用户反感 |
| 生态闭环 | 自夸但无意义 |
| 数智化 | 不是真实行业用词 |
| 降本增效 | 没数字时的废话 |
| 新质生产力 | 政策词，写作语境违和 |
| 护城河 | 投资圈词 |
| 底层逻辑 | AI 最爱用的"装深奥"词 |
| 综上所述 | 总结段标志 = AI 痕迹 |
| 随着...的不断深入 | 万能开头模板 |
| 作为 AI 模型 | 直接暴露身份 |
| 根据搜索 | 暴露 AI 在线检索 |
| 请咨询客服 | 客服话术，不该出现在内容里 |

**实测数据：**
- 改造前：14 词命中率 18% 
- 加自检层后：< 2%

## 必带规则（写工业 / B2B 内容时）

### 数字密度
- **每 200 字必有 1 个具体数字**（价格 / 数量 / 百分比 / 排名）
- 数字要具体到个位（"约 5500 元"比"几千元"强）
- 不要用"很多" / "大量" / "众多" / "广泛"

### 标准号
- 工业产品文 ≥ 1 条 GB/T xxxx 或 JB/T xxxx 或 ISO xxxx
- 化工类 ≥ 1 条 HG/T xxxx
- 电气类 ≥ 1 条 IEC xxxx
- 标准号要真实（编号能查得到）

### 产业带 / 城市
- ≥ 1 个具体产业带（不是"长三角""珠三角"这种宽泛区域）
- 工业带优先：苏锡常 / 佛山 / 温州乐清 / 柳市 / 慈溪 / 余姚 / 张家港 / 宁波镇海 / 东莞 / 泉州 / 中山
- 公司名只用公知品牌（三一 / 徐工 / 富士康 / 海尔），不编造小厂名

### 句式
- 主谓宾完整短句 > 长定语堆砌
- 不要 3 个逗号一路读到底的长句
- 段落 ≤ 8 句

---

## 反编造规则

| 不许 | 替代 |
|---|---|
| 编造具体公司名 | "本地厂家" / 公知品牌 / "按需问询" |
| 编造电话 | "详见站内联系方式" |
| 编造绝对价格 | 价格区间："约 5500-6200 元" |
| 编造产能数字 | "据公开报道约 xxx" 或省略 |
| 编造资质证书号 | 只引用确实存在的标准号 |

## Prompt 模板（最小可工作版）

```
你是 <具体身份+经历+心法>，给 <具体读者画像> 写 <文体>。

主题：<topic>

必须遵守：
1. 至少 3 个具体数字（价格/产量/排名/百分比）
2. 至少 1 条标准号（GB/T xxxx 或 JB/T xxxx 或 ISO xxxx）
3. 至少 1 个具体产业带（苏锡常/佛山/温州乐清/柳市/慈溪/...）
4. 不许出现：蓬勃发展/未来可期/赋能/生态闭环/数智化/降本增效/新质生产力/护城河/底层逻辑/综上所述/随着...的不断深入/作为AI模型/根据搜索/请咨询客服
5. 不许编造：具体公司名（除三一/徐工/富士康等公知）、电话、绝对价格点
6. 段落 ≤ 8 句；总长 ≥ 800 字

交付前自检（必须先列出来再开始写）：
[ ] 列出我会用的 3 个数字：________
[ ] 列出我会引的 1 条标准号：________
[ ] 列出我会提的 1 个产业带：________
[ ] 黑名单 14 词命中数：0

正文：
```

## 七层提示词架构（升级版）

四层是基础，guonika 实际跑七层：

1. **角色**：身份 + 经历 + 读者画像 + 心法
2. **情境**：当前在写什么类型的页 / 用在哪
3. **结构**：H1 / 段落 / FAQ 数量等硬约束
4. **规则**：必带 + 黑名单 + 反编造
5. **数据**：透传给 LLM 的真实数据（公司名 / 价格 / 城市 — LLM 不许改这些）
6. **自检**：交付前 5 项确认
7. **温度**：0.5 / 0.7 / 0.85 三档

`scripts/llm/llm_prompt_kit.php` 已经把这七层抽象好。
