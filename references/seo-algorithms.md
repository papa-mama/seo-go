# SEO 算法边界（百度 + Google）

## 百度 5 大算法（按 SEO 影响排）

### 1. 飓风算法（恶劣采集）

打击：
- 大量复制粘贴
- 段落级抄袭
- 跨站采集后批量发布

边界：
- 引用 OK，但需明确标注来源 + 自有评论 ≥ 50%
- 数据类（价格 / 标准号 / 城市）不算抄

### 2. 清风算法（标题党 + 薄页）

打击：
- 标题与正文不符
- < 400 字的内容页
- 同义词堆砌（"上海阀门 上海阀门厂家 上海阀门批发"）
- TDK 全是关键词不成句子

边界：
- ≥ 800 字 + 段落均匀
- title 长度 12-30 汉字
- description 80-160 字成完整句

### 3. 细雨算法（B2B 落地页低质）

**这个算法专门打 B2B 站**，必读：

打击：
- 标题作弊（"工业阀门厂家——批发零售一站式服务"这种）
- 落地页内容与标题不符
- 大量重复联系方式
- 联系方式藏在 image 里

边界：
- 标题写真实型号 / 价格段
- 联系方式可见但不堆砌
- 至少 2 段以上的产品介绍 + 数字

### 4. 惊雷算法（点击作弊）

打击：
- 刷点击 / 模拟用户行为
- 流量交易

边界：
- 不要买点击包年服务
- 自己网站内部跳转可以

### 5. 绿萝算法（垃圾外链）

打击：
- 友链交换平台
- 黑链 / 寄生虫
- 站群互链

边界：
- 友链 < 50 个
- 都是同行业相关站
- 不要交叉互链超过 3 度

## Google E-E-A-T

### Experience（经验）
- 作者必须实际接触过该产品 / 服务
- 文中有"我用了 6 个月"类的具体经验
- 体现为：作者署名页 + 经验描述

### Expertise（专业）
- 写阀门必须有阀门相关背景
- 引用标准 / 论文 / 行业报告
- author profile 显示资质

### Authoritativeness（权威）
- 站点整体在行业内有引用 / 提及
- 外链质量 > 数量
- Wikipedia / 行业协会 / 政府站引用是金标准

### Trustworthiness（可信）
- HTTPS + 有效证书
- 联系方式真实可验证
- 隐私政策 / 服务条款齐全
- 不诱导 / 不夸大

## 哪些算法 guonika 已合规

- ✓ 飓风：原创 + 数据类引用
- ✓ 清风：所有矩阵页 ≥ 800 字 + TDK 模板规范
- ✓ 细雨：标题模板含真实型号 / 区间 / 标准号
- ✓ 惊雷：从不刷点击
- ✓ 绿萝：友链 ≤ 30 个
- ✓ E-E-A-T：作者页 + 行业资质 + 引用 GB/T
